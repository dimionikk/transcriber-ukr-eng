# Транскрипція лекцій наживо

Записує все, що виходить з колонок (Zoom / Meet / браузер), і наживо
транскрибує через Whisper — щоб можна було прогорнути назад, якщо відволікся.

## Встановлення на новий комп'ютер

1. Встанови **Python 3.11+** (64-біт), познач "Add python.exe to PATH".
2. Завантаж репозиторій:

       git clone https://github.com/dimionikk/transcriber-ukr-eng.git
       cd transcriber-ukr-eng

3. Двічі клацни **`Launch.vbs`**.

## Як користуватись

Двічі клацни **`Launch.vbs`**, щоб відкрити вікно:

- Якщо чогось не вистачає (~1.5 ГБ), програма спитає дозвіл і сама встановить.
  Далі кожен запуск сама перевіряє компоненти — якщо все на місці, просто відкриває вікно.
- Зверху можна перемкнути **мову інтерфейсу** (Українська / English) — це мова
  кнопок і підписів самої програми, вона одразу оновлює екран.
- Окремо обери **мову лекції** (Українська / English) і натисни **▶ Почати**.
- Транскрипт заповнюється наживо.
- **⏹ Зупинити** зупиняє і зберігає запис.
- **📋 Скопіювати транскрипт** копіює все показане в буфер обміну.

Відеокарта NVIDIA не обов'язкова — без неї працює на процесорі (повільніше).

Кожен запуск зберігається в окрему папку:

    Records\Session DD.MM.YYYY\Session DD.MM.YYYY.txt

Під час запису:

- `Ctrl+Alt+M` ставить мітку "⭐ ВАЖЛИВО", `Ctrl+Alt+K` — "❓ НЕ ЗРОЗУМІВ" —
  зручно позначати місця, щоб повернутись до них пізніше.
- Якщо звук пропав (наприклад, відключились навушники), прийде сповіщення
  Windows і в транскрипті з'явиться рядок `⚠️`.

## Додатково

Розгорни **"Додатково"** на стартовому екрані — там зібрано все, що раніше
вимагало запуску окремих файлів чи прапорців командного рядка:

- підказка для розпізнавання (тема, імена, абревіатури) — помітно покращує
  точність на незвичних словах;
- вибір пристрою запису (якщо звук не з'являється — обери потрібний тут,
  замість `start.bat --list-devices`);
- модель, компроміс швидкість/якість, ширина променевого пошуку;
- пороги для розбиття на рядки й сегменти;
- клавіші-мітки (можна перепризначити або вимкнути);
- через скільки секунд тиші попереджати, і сигнал підтримки з'єднання.

`start.bat` лишається для консольного/діагностичного запуску
(наприклад `start.bat --list-devices`).

Все працює локально — жоден звук нікуди не надсилається.
